# Security policy

GitAccountSwitch hands GitHub tokens to git and `gh`, so security reports are taken seriously.

## Reporting a vulnerability

Please **don't open a public issue**. Report it privately through
[Report a vulnerability](https://github.com/SnowyFoxStudios/git-acc-switch/security/advisories/new)
on this repository. You'll get a reply as soon as possible, and fixes are released as a new version.

## Supported versions

Only the [latest release](https://github.com/SnowyFoxStudios/git-acc-switch/releases/latest) receives fixes.
